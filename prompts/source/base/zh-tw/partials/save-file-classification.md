## 檔案分類規則

### 各檔案職責

| 檔案 | 記錄內容 | 禁止記錄 |
|------|----------|----------|
| `{{FILE_ASSETS}}` | **主角擁有但非隨身**的金錢、房產／據點佈局、寄存於據點／旅館等物資 | 可隨身攜帶物品、魔法、裝備、**NPC 私人資產** |
| `{{FILE_TECH_EQUIPMENT}}` | **詳細設定/規格**：已開發或發現的技術、裝備、工具、載具 | 魔法本身、咒語、法術、**持有數量** |
| `{{FILE_WORLD_FACTIONS}}` | 勢力動態、世界觀拓展 (見下方詳述) | 個人任務、主角計畫、裝備／技術產品規格（→ `{{FILE_TECH_EQUIPMENT}}`） |
| `{{FILE_MAGIC_SKILLS}}` | 主角方**已習得、掌握或主動研發中**的術式原理、施法流程、魔法效果、戰鬥技能 | 使用魔法的裝備、魔法道具、**僅觀察到的 NPC 魔法** |
| `{{FILE_PLANS}}` | 主角接受的任務、個人目標、階段進度 | 世界事件、勢力動態 |
| `{{FILE_INVENTORY}}` | **主角擁有且隨身可動**的武器、防具、消耗品、材料、魔法道具、**金錢／通貨**（口袋／背包／便攜空間等，是否屬於「隨身」由你依設定判斷） | 不動產、大型載具、**詳細設定**、**NPC 私人物品** |

> **【主角擁有限定】**：`{{FILE_ASSETS}}` 與 `{{FILE_INVENTORY}}` 都**僅**記錄主角本人擁有之物。同伴、女主角、僱主、暫居處主人等 **NPC 的私人物品與資產**請寫入 `{{FILE_CHARACTER_STATUS}}` 該 NPC 條目下的 `### 已知持有重要物品`。即使主角短期受人收留、寄宿、被當小白臉，亦**不可**將收留者的物資視為主角持有。

> **【隨身判準】**：`{{FILE_INVENTORY}}` 與 `{{FILE_ASSETS}}` 都記主角擁有物，兩者的**唯一分界是是否隨身**——在身上（口袋／背包／魔法儲物空間等隨身載體）→ `{{FILE_INVENTORY}}`；放在非隨身處（據點、藏匿處、家中抽屜等任何不隨身的地方）→ `{{FILE_ASSETS}}`。**金錢、物品、材料一視同仁，無特例**：同一筆錢隨身就記在 `{{FILE_INVENTORY}}`、存放他處就記在 `{{FILE_ASSETS}}`。

**{{FILE_BASIC_SETTINGS}}**：**僅允許「既有條目增補」**，其餘一律寫入 `{{FILE_WORLD_FACTIONS}}`。
- **允許**：在既有條目下追加同類細節（例如「人文文化 / 飲食文化」既有條目下補一筆新菜餚範例）。`target` 必須是基礎設定中**真實存在**的片段，`replacement` **必須以原文完整保留 `target`** 為前綴，新內容**只能附加於其後**。
- **禁止**：新增頂層章節 / 子標題、改寫或刪除既有文字、調整既有條目順序、把 `target` 拆開重組。
- **context 必須是 BASIC_SETTINGS 中既有的標題路徑**；若該路徑不存在於基礎設定，**不可**強塞為新章節，請改寫入 `{{FILE_WORLD_FACTIONS}}`。
- 新登錄的勢力／地點／物產／NPC 等世界觀拓展仍走 `{{FILE_WORLD_FACTIONS}}`，**只有**對既有設定條目的細節補完才動 BASIC_SETTINGS。

> [!IMPORTANT]
> **物品歸檔絕對原則**：**持有事實**與**詳細設定**分兩條軸，別混為一談。
> - **持有事實**：主角當前持有的實體物品，「擁有 X×N」這筆紀錄依【隨身判準】記於 `{{FILE_INVENTORY}}`（隨身）或 `{{FILE_ASSETS}}`（非隨身）。
> - **詳細設定依物品性質分流**：
>   - **裝備／工具／載具／技術產品**——規格、性能、研發原理 → `{{FILE_TECH_EQUIPMENT}}`。**嚴禁**將這類規格寫入 `{{FILE_WORLD_FACTIONS}}`，即使它含豐富歷史背景；背景改用該條目下的**「備註」**欄記錄傳說或原理。
>   - **勢力信物／身分徽記／聖器／遺物**——本質是勢力 lore（其價值在來歷與代表意義，而非裝備性能）→ `{{FILE_WORLD_FACTIONS}}` 的「關鍵物品」範圍，**即使由主角持有**（持有那筆紀錄仍留在 `{{FILE_INVENTORY}}`／`{{FILE_ASSETS}}`）。
> - **技術類**：研發出的新技術產品（如新型槍械、機械裝置）屬於 `{{FILE_TECH_EQUIPMENT}}`，不可視為「勢力動態」。
> - 範例：
>   ```markdown
>   ## 古代短劍 (阿卡迪亞式)
>   - **類型**: 單手劍
>   - **描述**: 採用與遺跡同源金屬鑄造，具備良好的魔力傳導性。
>   - **備註**: 遺跡守衛者的制式配劍。此合金為阿卡迪亞文明特有材料。
>   ```

### `{{FILE_WORLD_FACTIONS}}` 記錄範圍
- **勢力動態**：主要/次要/已退場勢力的性質與目前狀態
- **核心世界觀**：重大世界設定（如威脅來源、神器背景）
- **關鍵物品**：劇情關鍵的道具、聖器、遺物、勢力信物／身分徽記（含主角持有者——記其來歷與代表意義，持有那筆紀錄另在 `{{FILE_INVENTORY}}`／`{{FILE_ASSETS}}`）
- **特殊材料**：新發現的稀有材料來源與加工方式
- **異世界對應表**：香料、植物、食材的異世界↔地球對照
- **探索新增地標**：主角發現的城市、地點、店鋪等
- **地標狀態變更**：關鍵地點的狀態改變（如被摧毀、改建、占領等）

### 科技與裝備 vs 物品清單
- **`{{FILE_MAGIC_SKILLS}}`**：記錄**「已習得的能力」**。若主角學會了某個法術或武技，記錄於此。
- **觀察到的魔法與世界設定**：若某個魔法僅被**「觀察到」**（由 NPC 施展）或作為背景設定被發現，但主角**尚未習得**，應記錄於 **`{{FILE_WORLD_FACTIONS}}`**（歸類於核心世界觀或勢力動態）。
- **實體載體**：尚未習得的魔法卷軸或書籍，應記錄於 **`{{FILE_INVENTORY}}`**。

> [!IMPORTANT]
> **物品歸檔絕對原則**：
> 1. **詳細設定/規格**：凡是**新發現或研發**的裝備/道具，若有具體設定與性能描述，**必須**將其**詳細定義**記錄於 `{{FILE_TECH_EQUIPMENT}}`。
> 2. **習得技能**：**僅限**記錄主角方**實際習得、掌握或正在主動研發中**的法術與技能。
> 3. **持有狀態**：主角**實際持有**該實體物品（含卷軸、書籍）的事實，**必須**記錄於 `{{FILE_INVENTORY}}`。
> 4. **嚴禁**：不可將已習得技能寫入 `{{FILE_WORLD_FACTIONS}}`；不可將僅觀察到的 NPC 魔法寫入 `{{FILE_MAGIC_SKILLS}}`。
