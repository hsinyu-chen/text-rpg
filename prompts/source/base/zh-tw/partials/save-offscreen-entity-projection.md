### 既存條目的時間推演(本 ACT 未在 log 出現者)

當 ACT 跨度達到「數小時以上」時,你**必須對** `{{FILE_CHARACTER_STATUS}}` / `{{FILE_WORLD_FACTIONS}}` **內每個既存的人物 / 勢力條目**對其中本ACT沒提及者,評估其狀態是否該推演更新。狀態不只透過事件演化,時間流逝本身也會推動。

- **推演基礎僅限**:該條目既有 `**目前心態**` 或對應持續性計畫欄位 + ACT 跨度長度 + 既有 KB 客觀事實(地理 / 勢力結構 / 既有任務狀態 等)。
- **可推演欄位**:
  - `{{FILE_CHARACTER_STATUS}}`:`**目前狀態**`(傷勢自然恢復、體力恢復)、`**目前心態** / **當前目標**`(既有計畫的進展)、`**最後已知位置**`(僅當既有心態 / 目標載有明確移動意圖時)
  - `{{FILE_WORLD_FACTIONS}}`:勢力內部動向、跨勢力張力遞減 / 累積、既有計畫的進展
- **積極推演**:跨度足夠且既有心態 / 目標 / 計畫欄位有實質載入時,**主動**推進該 entity 的動向 — 角色依其既有目標行動,勢力依其既有計畫推進。**進展幅度嚴格限制在本 ACT 實際經過的時間內**(ACT 跨度 2 小時 → 只能推 2 小時做得到的事;**不可加速**、**不可預支未來時間**)。
- **物理狀態保守演化**:傷勢推進(重傷 → 養傷中 → 痊癒)只在跨度真正足夠時發生(重傷需數天、輕傷需時辰級;靜養條件不佳則更慢)。寧可保守留原狀,不要激進跳級。
